## 加载页 CG 替换

锁定游戏加载页背景图（存档注入，零 hook），并可进一步替换缓存 bundle 中的贴图（方案 A）。原理与逆向细节见《LOADING_CG_INJECT.md》：存档 `save_slot_<id>.json` 为 `Base64(AES-256-CBC+PKCS7(JSON))`，密钥明文存放于注册表 PlayerPrefs；加载页选图优先级为「锁定列表 `_forcedCharacterCgIdList` > 解锁池 `_cgIdList` > 默认」。

> **CG ID 三态模型**（上游 2026-08-12 确认）：
> - **键形式**（页面列表展示）：`Story_CG/10101_normal` / `Unit_CG/10101_normal`（catalog 注册的 Addressable key）
> - **存档字符串 ID**（`_cgIdList` 内容）：`CG/10101_normal`（官方）或 `BG/xxx`（自定义）——游戏拼 key = `"Story_" + ID + ".png"`，失败兜底 `"Unit_" + ID + ".png"`
> - **锁定对象**（`_forcedCharacterCgIdList` 元素）：`{"id": 10101, "gacksung": false}`——**仅支持人格 CG**（命名 `CG/<人格ID>_normal|_gacksung`）
>
> 两种锁定方案：
> - **方案 A（稳定，默认）**：人格 CG 写入锁定列表（对象数组），强制显示，游戏保存不覆盖
> - **方案 B（不稳定）**：非人格资源（`CG/Dummy`、`BG/xxx` 等）注入解锁池使其成为唯一候选；**游戏保存时会重建解锁池，条目可能失效，需重新注入**

### WebUI 使用

首次进入页面需阅读风险须知并勾选同意后才能解锁功能（本功能会修改游戏存档与缓存文件）。

> **操作前提：游戏必须完全退出。** 游戏运行时注入会被其退出时的存档覆写还原；页面顶部会出现红色警告条并阻止写操作。

1. **选择存档槽**：顶部下拉列出全部 `save_slot_*.json`（自动选中最新），切换后自动读取该存档的 CG 状态。
2. **查看当前状态**：「解锁池」为随机候选列表（可点 × 移除注入项）；「锁定列表」为强制显示的人格 CG（琥珀色，显示 `CG/10101_normal` 形式），点 × 单独移除。
3. **添加锁定**：输入 CG ID 后点「添加锁定」，自动路由：
   - **人格 CG**（`10101_normal`、`CG/10101_normal`、`Story_CG/10101_normal`）→ **方案 A**：写入锁定列表（即时生效、稳定）
   - **非人格资源**（`Dummy`、`BG/xxx` 等）→ 确认后走**方案 B**：注入解锁池（弹出说明其不稳定性）
   - 只输名字时自动从扫描结果解析分类
4. **扫描可用 CG**：点「扫描可用 CG」增量扫描 Unity 缓存 bundle（缓存命中自动跳过）并合并 catalog 全量 ID。结果列表支持：文本过滤（防抖）、缓存状态筛选（全部/仅已缓存/仅未缓存）、**「仅可锁定」筛选**（只显示人格 CG），滚动分块加载。「未缓存」= catalog 有效但本地未下载；「仅解锁池·方案B」= 非人格资源。
5. **预览**：点「预览」导出该 CG 的贴图缩略图（未缓存条目不可预览）。
6. **贴图替换（方案 A 配套）**：填入目标 CG ID、选择本地图片（png/jpg/webp），点「开始替换」——按原贴图的尺寸/格式/细节层次自动重编码并写回缓存 bundle（标记 `limbus_modded`），原始贴图数据留存用于「还原原图」。**推荐替换 Dummy**（`Story/CG/Default/Dummy.png`，冷门资源，不占用剧情立绘）后走方案 B 锁定。
7. **清除全部锁定**：清空锁定列表（二次确认后即时写入）。

### 注意事项

- 锁定/注入操作即时写入存档，**不做备份**，请自行留意存档安全。
- **方案 B 条目游戏保存后可能被重建**（SetCgIdList 用解锁 CG 池重建 `_cgIdList`），失效后重新注入即可；方案 A（锁定列表）不受影响。
- 替换的是 Unity 缓存 bundle，**游戏更新重新下载缓存后会还原**，需要重新替换。
- 部分压缩贴图格式无法重编码，此类 CG 仅可锁定、不可替换。
- `BG/xxx` 为合法存档格式，但需自建 bundle 并在 catalog 注册 `Story_BG/xxx.png` 键才有效，未注册时加载失败显示默认页。
- 自定义 CG ID 不在游戏黑名单（`LoadingCgExceptionDataList`）内，天然安全；但剧情/活动触发强制 CG 时会重建锁定列表（低概率）。
- 取消锁定：从锁定列表移除条目（或清除全部）；取消方案 B：从解锁池移除条目。

### 常见问题

**Q: 提示「注册表未找到密钥」？**
A: 请先正常启动一次游戏（生成 PlayerPrefs 密钥）再操作。

**Q: 提示「游戏正在运行」？**
A: 完全退出游戏（含后台进程）后再试；写入会被游戏退出时的存档覆写还原。

**Q: 替换后游戏里还是旧图？**
A: 确认替换成功且目标 CG 已锁定（方案 A 或 B）；若游戏已更新缓存，需重新扫描并替换。

**Q: 「10101_normal」显示为「仅解锁池·方案B」？**
A: 只有命名为 `<人格ID>_normal`/`<人格ID>_gacksung` 的资源才是人格 CG（方案 A）；其他资源（Dummy、背景图等）只能注入解锁池（方案 B）。

**Q: 为什么锁定后有时加载页显示默认图？**
A: 多为方案 B 条目已被游戏保存重建，重新注入即可；或目标 key 在 catalog 中不存在（自定义 `BG/` 未注册）。
