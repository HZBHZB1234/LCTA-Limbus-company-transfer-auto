# 配置汉化 API

在使用在线翻译服务之前，需要先配置相应的 API 密钥和参数。

## 配置步骤
1. **选择翻译服务**：从下拉列表中选择要配置的服务（如 DeepL翻译服务、百度翻译服务、LLM通用翻译服务 等）。
2. **填写 API 参数**：在"API配置"卡片中填写配置，留空即为默认（必填项除外），带有星号的为必填参数。
   - 对于 LLM 通用翻译服务，可以选择预设的 LLM 服务（如 OpenAI、Claude 等），基础地址和模型名称会自动填充。
   - LLM 通用翻译服务的参数 *系统提示词* *响应格式* *最大生成令牌数* 留空将使用内置默认值。
3. **保存配置**：点击"保存配置"按钮，将当前服务的设置存入程序。
4. **测试 API**：填写完成后可点击"测试api"按钮验证连接是否正常。正式翻译前建议先点击"测试api"验证连接。

## 服务状态
页面右侧的"服务状态"卡片会展示当前所选服务的详细信息：
- **服务描述与使用说明**：包括该服务的基本介绍、API 申请与使用注意事项。
- **控制台与文档链接**：可点击"控制台"前往密钥管理页面，或点击"文档"查看官方 API 文档。
- **支持的语言代码**：列出该服务支持的语言及其代码格式，填写翻译页面的语言代码时以此为准。

## API申请
绝大部分翻译服务都需要填写密钥。这可能会产生费用。如果不能接受，请看 `汉化包下载` 页面的 *LCTA-AU* 相关章节。  
个人建议使用 LLM 通用翻译服务，因为 LCTA 对于大语言模型具有特殊优化。在所有的 LLM 中，个人建议使用 DeepSeek，其性价比较高，同时作者进行测试时也使用的 DeepSeek。  
如果不想要付费，可以考虑使用带有免费额度的 LLM 或者翻译服务，比如百度翻译等。请自行查阅相关文档。  
如果您只想要进行测试，请使用"空翻译器(使用原文)"，这将返回原文。  
再次重申，如果您没有特殊需求，只是想要使用自动翻译，使用LCTA-AU可能是一个更好的选择。

## 常见问题解答

### 翻译失败，报错字样中带有 SSL Error
请关闭加速器或代理后重试。

### DeepSeek 报错402
请充值，不用太多。
更多DeepSeek报错码请看[DeepSeek API文档](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes)
