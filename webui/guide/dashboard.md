# 首页

LCTA 工具箱的主页面，提供整体状态概览和快速操作入口。

## 状态卡片

首页顶部有四个状态卡片，帮助你快速了解工具箱的配置情况：

- **汉化包状态**：显示当前已安装汉化包的数量。如果显示"未安装汉化包"、"未启用"或"无法检测"，请前往 **汉化包下载** 或 **安装已有汉化** 页面获取汉化包。
- **启动器配置**：显示 Launcher 的更新模式设置状态。如果显示"未配置"，请前往 **Launcher配置** 页面进行设置。
- **LCTA-AU 更新**：显示自动更新功能的开启状态。可在 **设置** 页面中修改。
- **API 配置**：显示已配置的翻译 API 服务数量。如果显示"未配置"，请前往 **配置汉化API** 页面进行设置。

每种状态卡片的颜色代表状态：
- **绿色**：已正确配置
- **黄色**：需要关注或配置
- **灰色**：无法检测或状态未知

## 快速操作

首页本身只提供状态概览，下列操作入口分别位于对应页面：

- **检查更新**：前往 **设置** 页面的"配置操作"区域，点击"检查更新"按钮手动检测 LCTA 是否有新版本可用。
- **快速上手**：通过首次使用窗口或帮助中心的“快速上手”卡片进入三步短流程。
- **帮助中心**：点击侧边栏任意导航按钮右侧的 **?** 图标，或长按键盘 **W** 键 2 秒打开帮助抽屉。
- **下载汉化包**：切换到 **汉化包下载** 页面进行下载。

## 导航提示

- 左侧边栏按功能分组排列，分为**常用工具**、**管理配置**和**系统**三个组。
- 搜索框可以快速筛选导航项，输入关键词即可。
- 点击侧边栏任意导航按钮右侧的 **?** 图标，可以打开该页面的对应帮助。
- 在任意页面长按键盘 **W** 键 2 秒即可打开当前页面的帮助文档。
