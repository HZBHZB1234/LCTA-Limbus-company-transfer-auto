# 快速上手

快速上手用于第一次认识 LCTA。它不会要求你完整配置工具箱，也不会保存单独的“向导进度”。

## 三步流程

1. **选择目标**：从“安装现成汉化”“自动更新并启动”“自己翻译文本”“模组与文本玩法”中选择当前最想完成的一项。
2. **必要设置**：只显示该目标真正需要检查的设置，例如游戏目录、Launcher 更新方式或翻译服务状态。
3. **立即开始**：保存必要设置，并直接进入下载、安装、Launcher、翻译或管理页面。

## 四种目标

- **安装现成汉化**：进入汉化包下载页选择 LLC、LCTA-AU 或 OurPlay；已有汉化包时可直接进入安装页。
- **自动更新并启动**：设置 Launcher 的更新方式和可选处理，然后进入 Launcher 配置页复制 Steam 启动命令。
- **自己翻译文本**：检查是否已经保存翻译服务配置；未配置时先进入 API 配置页，已配置时可直接进入翻译工具。
- **模组与文本玩法**：按需打开模组管理、文本美化或调爪文本下载入口。

## 说明

- 快速上手不会隐藏或关闭未选择的功能。
- 网络、缓存、并发和其他高级选项留在对应功能页中。
- 游戏目录可以在快速上手中设置，也可以稍后在设置或安装页面补充。
- 退出快速上手不会影响已经保存的普通配置。

需要详细说明时，点击侧边栏条目旁的 **?**，或长按 **W** 两秒打开当前页面帮助。
