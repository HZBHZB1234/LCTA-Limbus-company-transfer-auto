# Launcher配置

如果你希望汉化包能够自动保持最新、MOD 自动加载，那么你需要配置 LCTA Launcher。Launcher 通过替换 Steam 启动命令来实现自动化。

## 使用步骤

1. **配置各汉化源的下载选项**（零协汉化、OurPlay、LCTA-AU），下载相关选项可参考 **汉化包下载** 页面的帮助文档，Launcher 特有选项以本页说明为准。
2. **设置工作模式**（详见下方说明）。
3. 点击 **保存配置**。
4. 点击 **复制** 按钮复制生成的 Steam 启动命令。
5. 打开 Steam → 游戏库 → 右键 Limbus Company → 属性 → 通用。
6. 在"启动选项"文本框中粘贴复制的命令。
7. 此后通过 Steam 启动游戏时，Launcher 将自动按配置执行汉化更新和维护。

> **注意**：如果你移动了 LCTA 程序的安装位置，需要重新复制并更新 Steam 启动命令。

## 下载配置

### 零协汉化配置
- **压缩格式**：选择 ZIP 或 7Z。ZIP 兼容性更好，7Z 文件更小。
- **文本下载来源**：从github下载（GitHub 直连）或从公益镜像下载 (Beta)（Webnote API，有延迟）。
- **使用代理加速下载**：建议开启，解决国内访问 GitHub 不稳定的问题。
- **使用本地字体缓存**：使用已缓存的字体文件，避免重复下载。

### OurPlay 配置
- **API源**：PC API（原版接口）或 Android API (支持神人汉化)（新版接口，需基板包辅助转换格式）。选择 Android API 后出现以下联动选项（均仅 Android API 源有效）：
  - **下载正经版本汉化（关闭则下载神人汉化）**：开启时下载正经版汉化，关闭后下载神人汉化。
  - **基板包路径（可选）**：用于将手机版汉化包格式转化为通用格式，支持目录或 zip 文件。留空则自动从游戏安装目录检测。
- **字体处理选项**：保留原字体 / 精简字体 / 使用本地字体缓存。
- **使用API获取版本信息**：通过 Webnote API 检查更新。**具有延迟**，适合直连获取版本信息失败时使用，直连失败时再开启。

### LCTA-AU 汉化配置
- **文本下载来源**：从github下载 或 从公益镜像下载 (Beta)。
- **使用代理加速下载**：建议开启。

## 工作模式配置

- **更新模式**：选择启动时自动更新的汉化源组合：
  - `不自动更新`：仅启动游戏，不进行任何更新检查。
  - `仅零协更新`：只检查和更新零协会汉化包。
  - `仅ourplay更新`：只检查和更新 OurPlay 汉化包。
  - `仅LCTA-AU更新`：只检查和更新 LCTA-AU 汉化包。
  - `更新llc+ourplay`：自动在零协和 OurPlay 之间选择较新的汉化源进行更新。
  - `更新llc+LCTA-AU (github)`：自动在零协和 LCTA-AU（GitHub 源）之间选择较新的汉化源进行更新。
  - `更新llc+LCTA-AU (API Beta)`：自动在零协和 LCTA-AU（API 源）之间选择较新的汉化源进行更新。

- **启用MOD支持**：启动游戏时加载 Mods 文件夹中的模组。
- **启用文本美化**：更新汉化包后自动应用文本美化规则。相关设置请在 **文本美化** 页面配置。
- **启动时自动进行CDN优选**：启动游戏前自动测试并选择最快的 CDN 节点。
- **自动写入hosts**：CDN 优选后自动将最优 IP 写入系统 hosts 文件。**默认开启**，需要管理员权限，权限不足时会尝试 UAC 提权。
- **CDN缓存有效期**：CDN 优选结果的有效时间（小时）。**默认 24 小时**；设为 0 表示每次启动都重新测速。
- **启用GUI进度窗口**：在 Launcher 模式下显示图形化进度窗口，实时展示更新、CDN 优选和游戏启动的状态与日志。关闭则使用传统的控制台模式。

## Steam 启动命令

Steam 启动命令由程序自动生成，内容为 LCTA 启动器路径及 `-launcher` 参数，游戏路径等配置由启动器读取本地配置获得。点击输入框旁的 **复制** 按钮即可复制到剪贴板。
