# Mod 镜像站

在 LCTA 内嵌窗口中浏览 Limbus Mod 镜像站（N 网 Mod 标准版镜像），站内下载的「标准版」包由 LCTA 接管：aria2c 高速下载、完整性校验、自动安装到 mod 目录，下载普通文件则保存到系统「下载」目录。

---

### 打开方式

点击侧边栏「Mod 镜像站」按钮，会打开一个独立窗口加载站点页面，与主程序并行使用。

### 登录与登录态

镜像站使用站内账号体系。在站点页面登录后，登录令牌会自动同步保存到 LCTA 配置（`ui_default.mod_mirror.auth`），关闭窗口或重启 LCTA 后再次打开仍保持登录态，无需重复登录。

- 登录 / 登出 / 令牌刷新均会自动同步，无需手动操作。
- 页面加载时自动从宿主恢复登录态（等待宿主桥就绪后恢复，失败时保留本地状态）。

### 下载标准版

1. 在 Mod 详情页点击「下载标准版」，进度模态窗会显示下载进度；
2. LCTA 优先使用内置 aria2c 多连接高速下载：
   - 站点 API 域会拦截 aria2c 的 TLS 指纹，下载前先经内置网络栈解析 302 拿到 CDN 直链，再交给 aria2c 分段下载，兼顾速度与兼容性；
   - 未找到 aria2c 或下载失败（如直链被拒）时自动降级为内置下载器，不影响使用。
3. 下载完成后校验文件大小与 SHA-256，校验通过后自动解压安装到 mod 目录（对应同名的旧版本目录会被覆盖）；
4. 安装完成提示「重新启动游戏后生效」——Launcher 启动游戏时自动扫描 mod 目录并加载。

### 下载普通文件

Mod 详情页的普通文件列表（差分包 / 原版文件等）点击下载后，保存到系统「下载」目录，不做自动安装。

### 注意事项

- 标准版安装目标为 LCTA 配置的 mod 目录（「设置」页面可查看），安装后由启动游戏时的 Launcher 自动加载。
- 下载进度模态窗可随时取消；取消后已下载的临时文件会留在暂存目录，下次下载自动覆盖。
- 压缩包内的文件会经过路径安全校验，包含路径穿越等不安全成员的包会被拒绝。

### 常见问题

**Q: 点击下载后一直停在「正在准备下载」？**  
A: 通常是站点或 CDN 暂时不可达，等待数秒后会自动继续；仍无进度可关闭窗口重试。

**Q: 下载很慢 / 进度条不动？**  
A: 正常情况下使用 aria2c 多连接下载；若 aria2c 不可用或直链被拒，会自动降级为内置下载器（单连接），速度取决于网络。

**Q: 下载完成但游戏里看不到 Mod？**  
A: 需要重启游戏生效（通过 LCTA Launcher 启动时会自动扫描 mod 目录）。如果是从旧版本升级，旧目录已被覆盖，无需手动清理。
