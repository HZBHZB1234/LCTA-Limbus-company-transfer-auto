# 抓取专有词汇

通过 ParaTranz API 下载专有名词表并解析，生成词汇表供翻译时使用。专有名词表可以帮助翻译服务更准确地翻译人名、地名、技能名等专有术语。

## 使用场景

- 在使用 LLM 翻译前，先抓取专有词汇，提高翻译一致性。
- 生成词汇表用于其他机翻工具的词汇库。
- 更新专有名词表以适配游戏新版本内容。

## 抓取配置

### 输出格式
- **JSON 格式**：生成标准的键值对 JSON 文件。这是 LCTA 翻译功能支持的唯一格式。
- **单文件格式**：每行按"原词+分隔符+译词"连接成一个文本文件，可用于部分机翻工具的词汇库。
- **双文件格式**：分别保存原词和译词到两个文件，可用于部分机翻工具的词汇库。

### 过滤选项
- **跳过含空格的词汇**：过滤掉包含空格的短语，减少噪音词条。短语类词汇通常不适合作为专有名词使用。
- **最大词汇数量**：限制提取的词条总数，留空表示无限制。建议设置一个合理的上限以避免词汇表过大。
- **最短专有名词长度**：只提取字符数大于等于此值的词条，减少短词匹配导致的错误。建议设置为 2 或以上。

### 输出设置
- **分隔符**：仅在单文件格式有效。分隔每行中的"原词"与"译词"，默认值为 `|||`。可以根据目标机翻工具的要求自定义。

## 开始抓取

配置完成后点击"抓取专有词汇"按钮。抓取过程可能需要一定时间，请耐心等待。

## 输出文件

抓取完成后，输出文件保存在**程序运行目录**（LCTA.exe 所在目录）下，文件名取决于选择的输出格式：

- **JSON 格式**：`proper.json`
- **单文件格式**：`term_translation.txt`（每行"原词+分隔符+译词"）
- **双文件格式**：`term.txt`（原词）与 `translation.txt`（译词）

## 在翻译中使用

抓取完成后，在 **翻译工具** 页面：

1. 勾选"启用专有名词"
2. 如需使用本页面抓取的词汇文件，关闭"自动抓取专有词汇"，并手动指定专有名词文件路径为程序运行目录下的 `proper.json`（JSON 格式输出）
3. 若保持"自动抓取专有词汇"开启，翻译流程会在翻译时自行从 ParaTranz API 抓取专有词汇，不使用本页面生成的产物
