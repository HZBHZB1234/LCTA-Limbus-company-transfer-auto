# 游戏资源更新

提前下载游戏官方的 Localize 与 AssetBundle 资源，减少版本更新后首次进入游戏内容时的等待。

---

### 手动更新

1. **确认游戏目录**：游戏目录与主程序共用，在 **设置** 页面的「游戏路径」中配置。本页面只读显示当前目录，未配置时可点击「前往设置」跳转；配置完成后点击「检测」验证游戏文件并读取 CDN 令牌。
2. **选择更新范围**：Localize 可单独选择日文、英文、韩文；AssetBundle 会写入 Unity 使用的本地缓存。
3. **选择下载策略**：自动模式会优先使用随程序打包的 `aria2c`，不可用时回退到 Python 内置下载器；并发数推荐保持为 8。
4. **开始更新**：点击「开始更新」后，页面会分别展示资源清单、Localize 与 AssetBundle 的进度。
5. **取消任务**：取消会安全停止后续下载，已经完成的缓存文件会保留，下次更新可继续复用。

手动更新不会使用 Launcher 的版本指纹跳过逻辑，每次都会根据当前游戏文件重新读取 CDN 令牌并检查所选资源。
运行详情统一写入工具箱日志，可在「日志」页面或 `logs/app.log` 中查看。

### Launcher 自动预下载

Launcher 可在启动游戏前自动预下载官方资源，开关位于 **Launcher 配置** 页面「工作模式」中的「游戏版本更新后自动预下载资源」，本页仅提供集成介绍与跳转按钮。

开启后，Launcher 会在启动游戏前计算 `LimbusCompany.exe` 的 SHA-256。该版本变化判断完全基于本地文件，不需要联网检查。

当指纹变化，或上次完成的资源范围不包含当前配置时，Launcher 才会执行预下载。自动更新失败不会阻止游戏继续启动，详细错误会写入日志。

### 注意事项

- 请确保游戏目录完整，且当前用户对游戏目录和本地缓存目录具有写入权限。
- 强制选择 aria2c 时，如果程序包内和系统 PATH 中都找不到 `aria2c.exe`，任务会失败；不确定时使用「自动」。
- Localize 部署会覆盖对应官方语言目录中的同名文件，不会修改汉化工具自身的翻译源文件。
- AssetBundle 数量可能较多，更新时间取决于网络速度与官方资源规模。
- Bundle 下载失败或取消时，会清理该失败项创建的 Unity 缓存目录，避免残留空目录或不完整文件。

### 常见问题

**Q: 页面提示游戏目录无效？**  
A: 请在 **设置** 页面确认配置的是游戏根目录（包含 `LimbusCompany.exe`），而不是 `LimbusCompany_Data` 子目录。

**Q: 为什么进度长时间停留在资源清单？**  
A: 该阶段需要读取官方目录并解析 Bundle 清单；网络不稳定时可能较慢，可前往「日志」页面确认是否仍在工作。

**Q: 手动更新完成后，Launcher 还会再次更新吗？**  
A: 页面会记录实际完成的资源范围。若已覆盖 Launcher 当前配置且游戏指纹未变化，Launcher 会跳过重复工作。
