# 服务器切换

配置 lethe 私服路径并发送桌面快捷方式：双击快捷方式即可自动同步私服资源并启动私服，无需手动执行切换。

---

### 背景

lethe 私服与官服的资源（Addressables Bundle）绝大多数完全一致，只有少量独有资源随版本变化。两服共用同一个 Unity 缓存目录。切换服务器时如果清空整个缓存，会导致公共资源全部重新下载（约 14 GB）；本功能只处理差异资源：lethe 独有且缺失的从对应 CDN 补下载，另一服独有且存在的缓存条目移除，公共资源不动。

### 目录设置

1. **官服目录**：与主程序共用，在 **设置** 页面的「游戏路径」中配置。
2. **lethe 目录**：选择 lethe 私服分发包所在文件夹（包含 `LimbusCompany.exe` 与 `LimbusCompany_Data` 的目录），可点击「检测」验证。

两个目录配置完成后即可发送快捷方式。

### 开启私服快捷方式

点击「发送到桌面」会在桌面创建「开启 lethe 私服」快捷方式。双击该快捷方式会：
1. 先把共享缓存同步到 lethe 私服状态（补齐 lethe 独有资源）；
2. 再启动 lethe 私服的 `LimbusCompany.exe`（lethe 分发包自带 BepInEx/Doorstop 注入，直接运行游戏主程序即可进入私服）。

同步每次都会重新计算差异集合，自动适配两服「偶尔有所差异」的版本变化。

### Launcher 自动恢复

Launcher 可在启动官方游戏前自动把缓存恢复到官服一致状态，开关位于 **Launcher 配置** 页面「更新集成」中的「开启官服前自动恢复官服资源」，本页仅提供集成介绍与跳转按钮。

开启后，通过 Launcher 启动官方游戏前会先执行一次「切回官服」的缓存同步。这样在 lethe 私服游玩后直接回到官方，也不会触发官服资源重复下载。该功能**只用于恢复官服资源**，不会自动切到 lethe。

### 注意事项

- 请确保两个目录都完整，且当前用户对 Unity 缓存目录（`AppData\LocalLow\Unity\ProjectMoon_LimbusCompany`）具有写入权限。
- 移除缓存条目是不可逆操作，但公共资源不受影响。
- 同步失败不会影响游戏启动，游戏运行时会自行下载缺失资源；详细错误写入 `logs/app.log`。

### 常见问题

**Q: 页面提示 lethe 目录无效？**  
A: 请选择 lethe 私服分发包的根目录（包含 `LimbusCompany.exe` 与 `LimbusCompany_Data` 的文件夹），而不是其中的 `LimbusCompany_Data` 子目录。

**Q: 双击快捷方式后很快完成（0 下载 0 移除）？**  
A: 说明两服当前目录下的资源差异已经与目标一致（或差异 bundle 已在缓存中），属于正常情况；每次运行都会重新计算差异。

**Q: 通过快捷方式进入私服后游戏还是提示下载？**  
A: 请确认启动的是 lethe 私服版本；如果游戏版本刚更新，两服差异集合可能尚未包含最新内容，游戏运行时会补充下载少量资源。
