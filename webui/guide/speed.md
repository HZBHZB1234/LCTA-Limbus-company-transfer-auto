## 游戏加速

基于 [OpenSpeedy](https://github.com/game1024/OpenSpeedy) 的游戏速度控制功能，通过 DLL 注入 + Windows 时间 API Hook 实现对 `LimbusCompany.exe` 的变速。

---

### WebUI 使用

首次进入页面需要同意免责声明才能解锁功能。

1. **进程状态**：页面会自动检测 `LimbusCompany.exe` 的运行状态。
2. **注入/弹出**：点击「注入」按钮，将 OpenSpeedy 的 DLL 注入游戏进程。注入成功后该按钮会变为「弹出 DLL」，点击同一个按钮即可移除 DLL 并恢复游戏正常速度。
3. **变速**：通过滑块或预设按钮（1x/2x/3x/5x）选择倍率，点击「应用」生效。应用倍率需先注入 DLL，未注入时点击会提示"请先注入 DLL"。

---

### Launcher 模式

在 **Launcher 配置** 页面「工作模式」中开启「在 Launcher 模式下启用游戏加速」后，通过 Steam 启动游戏将自动注入加速并注册以下全局热键（本页仅提供集成介绍与跳转按钮）：

| 热键 | 功能 |
|------|------|
| `Ctrl+S` | 在 1.0x 和设定倍率之间切换 |
| `Ctrl+Shift+S` | 弹出倍率选择窗口，拖动滑块并点击「应用」选择倍率 |

其中"设定倍率"可在 Launcher 配置页「工作模式」的「热键加速倍率」输入框中配置（默认 2.0x，范围 0.1x – 10x）。通过倍率选择窗口设置的倍率会一直生效，并非临时倍率。

- 热键仅在 `LimbusCompany.exe` 游戏窗口处于前台时生效。
- 注册热键需要已同意免责声明（在游戏加速页面勾选"我已了解上述风险"并点击「确认」）。
- 热键仅在 Launcher 模式下生效，WebUI 页面不注册热键。

### 常见问题

**Q: 杀毒软件报毒怎么办？**
A: DLL 注入行为可能被杀软误报。请将 openspeedy 包 data 目录中的 speedpatch DLL 加入杀软白名单。

**Q: 提示"游戏未运行"？**
A: 启动 `LimbusCompany.exe` 后稍等片刻即可，页面状态每 2 秒自动更新（进程检测按进程名进行，无需通过 Steam 启动）。

**Q: 提示"权限不足"？**
A: 如果游戏以管理员权限运行，LCTA 也需要以管理员权限运行。

**Q: 速度倍率有什么限制？**
A: OpenSpeedy 支持 0.001x – 1000x，但建议使用 0.1x – 10x 范围。过高倍率可能导致游戏错误或崩溃。
