# 翻译工具

将游戏文本（韩文、日文、英文）自动翻译成中文。支持多种翻译服务，包括在线翻译 API 和本地 LLM。

## 使用流程

1. **配置翻译服务**：先在 **配置汉化API** 页面配置好翻译服务的 API 密钥（如 Deepseek、百度翻译等）。
2. **设置翻译选项**：根据需求启用各项翻译选项（详见下方说明）。
3. **选择翻译服务**：在下拉框中选择已配置的翻译服务。
4. **开始翻译**：点击底部"开始翻译"按钮，在弹出的进度窗口中等待完成。

## 翻译选项

### 专有名词相关

- **启用专有名词 (LLM翻译专用)**：翻译时参考专有名词表，提高人名、地名等术语的翻译一致性。该选项默认开启。如果出现大量匹配错误请关闭。
- **在进行翻译时自动抓取专有词汇 (无法使用自定义设置)**：翻译过程中自动重新提取专有词汇。如需使用自定义专有名词文件，请关闭此选项并在下方手动指定文件路径。
- **专有名词json路径**：关闭自动抓取后，可手动指定自定义的专有名词 JSON 文件。

### LLM 翻译专用选项

- **启用人物角色标识**：为 LLM 翻译添加上下文标记，帮助模型理解当前文本属于哪个角色，提升角色对话翻译准确性。
- **启用状态效果标识**：为 LLM 翻译添加状态效果标记，帮助模型理解技能描述中的游戏机制术语。

### 高级选项

开启"启用高级选项"后，可手动指定各语言的源文本路径：

- **韩文文本路径**：原始韩文游戏文本所在的文件夹。
- **日文文本路径**：日文游戏文本所在的文件夹。
- **英文文本路径**：英文游戏文本所在的文件夹。
- **中文文本路径**：参考中文文本所在的文件夹（通常为零协会汉化文本）。如果未安装零协会汉化，需要手动指定此路径。
- **文件名存在前缀**：按带前缀的文件名格式处理源文件。

> 通常情况下无需手动设置以上路径，程序会自动检测。仅在自动检测失败或需要特殊处理时才需手动配置。

### 其他选项

- **转储过程内容以供分析**：将请求文本与响应文本输出至日志，方便调试和问题排查。

## 翻译服务配置

- **翻译服务**：在下拉列表中选择已配置好的翻译服务，如 **百度翻译服务**、**Google翻译服务**、**DeepL翻译服务**、**LLM通用翻译服务** 等。LLM 相关服务需先在 **配置汉化API** 页面配置好密钥后才会出现在下拉列表中。
- **失败时进行相反重试 (LLM翻译专用)**：LLM 返回格式错误时切换请求格式重试。**建议开启**，否则可能出现较多漏翻。
- **请求 / 响应格式**：选择请求与响应的数据格式，共三种选项：
  - **XML 请求 → JSON 响应（推荐）**：默认选项，兼顾结构化与解析可靠性。
  - **JSON 请求 → JSON 响应**：适合偏好纯 JSON 的场景。
  - **XML 请求 → XML 响应**：在某些模型上格式遵循度更高。
- **使用源语言 (除LLM翻译外使用)**：选择要翻译的源语言 —— 英文、日文或韩文。LLM 翻译无需选择此项。

## 高级管线配置

此卡片用于调优翻译管线的并发、模式与质量校验：

- **并发线程数**：并发翻译的最大线程数（1 - 16）。数值越大翻译越快，但过高可能导致 API 限流或被暂时封禁。建议保持默认值 4。
- **启用并发处理**：开启后多个文件将并行翻译，大幅提升整体速度；关闭则逐个文件串行处理，速度较慢但更稳定。
- **翻译模式**：**多阶段翻译**（推荐）按"消歧 → 翻译 → 自检"三阶段管线执行，质量更高但耗时更长；**单阶段翻译**直接翻译，速度更快但可能遗漏上下文匹配。
- **启用翻译自检**：翻译完成后由 LLM 自行检查翻译质量并修正明显错误。可提升质量，但会增加 API 调用次数和耗时。
- **启用LLM思考模式**：启用后 LLM 将在翻译前进行深度思考（chain-of-thought），提高翻译质量，但会增加 API 响应时间和 token 消耗。DeepSeek 使用原生思考模式，其他 LLM 使用通用 reasoning_effort 参数。
- **启用规则化后处理校验**：在 Stage 1 翻译完成后、Stage 2 LLM 校验前，使用确定性规则引擎检测并自动修复机械性错误（如 Buff ID 中误用空格、特殊效果引用缺失）。仅对技能文件生效。
- **消歧模式**：**混合模式（推荐）**：相似度匹配优先，必要时使用 LLM 消歧；**相似度匹配**：仅用 Jaccard 相似度进行 JP/EN 交叉验证；**LLM消歧**：完全由 LLM 判断专有名词归属。
- **最低匹配置信度**：专有名词匹配的最低置信度阈值。推荐使用"中"；**高**只采纳最确定的匹配，漏翻可能增加；**低**采纳更多匹配但可能引入错误。

## 开始翻译

配置完成后点击 **开始翻译** 按钮启动翻译任务。翻译过程中：

- 进度窗口会显示当前翻译状态和进度百分比。
- 支持**暂停 / 继续**翻译任务。
- 支持**取消**翻译任务（已翻译的部分会保留）。
- 可**最小化**进度窗口，在右下角查看迷你进度条。

可点击 **查看翻译日志** 按钮查看每次翻译的 API 调用记录与处理详情。
