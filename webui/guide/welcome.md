# 欢迎使用 LCTA 工具箱

LCTA 提供以下主要功能：

- 下载 LLC、LCTA-AU 或 OurPlay 汉化包，并安装已有汉化包。
- 通过 Launcher 在启动游戏前检查汉化更新，并按配置处理模组、文本美化或调爪文本。
- 配置受支持的翻译服务，自行处理游戏语言文件。
- 管理已安装汉化包和模组，应用或编辑文本美化规则。
- 使用 CDN 优选、游戏变速、清理和日志等辅助工具。

## 第一次使用

点击首次使用窗口中的 **开始快速上手**，或从帮助中心进入 **快速上手**。流程只有三步：

1. 选择当前最想完成的目标。
2. 检查该目标必需的设置。
3. 直接进入真正执行操作的页面。

快速上手不会要求你配置所有选项，也不会关闭未选择的功能。

## 获取帮助

- 点击侧边栏导航项旁的 **?** 查看当前功能说明。
- 长按键盘 **W** 两秒打开当前页面帮助。
- 遇到问题时查看 **日志** 页面；反馈渠道位于 **关于** 页面。
