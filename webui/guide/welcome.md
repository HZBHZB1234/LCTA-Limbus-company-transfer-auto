# 欢迎使用 LCTA 工具箱

LCTA 提供以下主要功能：

- 下载 LLC、LCTA-AU 或 OurPlay 汉化包，并安装已有汉化包。
- 通过 Launcher 在启动游戏前检查汉化更新，并按配置处理模组、文本美化或调爪文本。
- 配置受支持的翻译服务，自行处理游戏语言文件。
- 管理已安装汉化包和模组，应用或编辑文本美化规则。
- 使用 CDN 优选、游戏变速、清理和日志等辅助工具。

## 第一次使用

不需要先理解所有设置。你可以直接：

1. 在 **汉化包下载** 页选择 LLC、LCTA-AU 或 OurPlay 来源下载汉化包。
2. 在 **安装已有汉化** 页把下载好的汉化包安装到游戏目录。
3. 之后按需使用 Launcher 自动更新、文本翻译、文本美化等功能。

工具箱不会强制你配置所有选项，未使用的功能也不会被关闭。

## 获取帮助

- 点击侧边栏导航项旁的 **?** 查看当前功能说明。
- 长按键盘 **W** 两秒打开当前页面帮助。
- 遇到问题时，反馈渠道位于 **关于** 页面。
