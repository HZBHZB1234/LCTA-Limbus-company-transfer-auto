LLM 文本美化

使用 bus 语法匹配文本组，交由 LLM 美化，输出 bus 引擎格式规则集（自动保存至 fancy/ 并启用）。

匹配规则（bus 语法） path 支持 key、[*] 通配、[索引]、[?字段=值] 选择器；path 为空表示匹配全部字符串叶子。例如 dataList[?id=10100201].name 只匹配指定技能的名称；dataList[*].desc 匹配所有技能的描述

文件匹配器支持 glob 字符串、{"exact": "..."} 或 {"regex": "..."}

排除规则集（避免重复处理） 勾选的 bus 规则集会先模拟执行，已被其命中的文本路径将不送 LLM
