倍率设置

敌方单位受到的伤害将乘以该倍率（默认 3.0，范围 0.1 - 1000）。"无修正"（按 1.0 处理）的伤害直接置为倍率值。我方单位不受影响。
开启后，hook 在战斗中对实际生效的伤害事件记录一条日志（目标/攻击方/暴击/倍率前后值），逐条写入本地日志（logs/app.log，可在「日志」页查看），上方"最近日志"仅显示最新一条。默认关闭以降低开销。

偏移数据

本功能所需的函数偏移不内置在程序中，而是从远程 JSON API 获取并按本地 GameAssembly.dll 的 SHA-256 做版本锚定缓存。游戏更新后偏移自动失效并重新拉取。

默认 web.lcta.top 提供的偏移 JSON；可改为任意返回相同格式的地址。

Launcher 集成

开启后，通过 Launcher 启动游戏将自动等待游戏进程并注入，无需进入本页操作。

开关请在 Launcher 配置页的「工作模式」中勾选「启用伤害倍率」。
